# Decisiones de arquitectura (ADR) — índice

Registros de las decisiones técnicas importantes del proyecto. Cada ADR explica
el contexto, la decisión y sus consecuencias.

## Formato

Cada archivo sigue la plantilla:

```
# ADR NNN — Título

## Estado
Propuesta | Aceptada | Reemplazada por ADR-XXX | Obsoleta

## Contexto
¿Qué problema o situación motiva la decisión?

## Decisión
¿Qué se decidió?

## Consecuencias
Positivas, negativas y neutrales.
```
