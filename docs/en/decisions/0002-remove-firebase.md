# ADR 0002 — Remove Firebase/FCM from the mobile client

## Status
Accepted

## Context

The initial version used Firebase Cloud Messaging (FCM) for push notifications
from the backend to the phone. This forced including `google-services.json`,
setting up a Firebase project and added dependencies that complicated the build
(especially without access to the Firebase console).

## Decision

**Remove Firebase/FCM from the mobile client.** Notifications become **local**
(`flutter_local_notifications`) generated by the app itself.

## Consequences

**Positive**
- The app builds without `google-services.json`.
- Fewer dependencies and less configuration.
- Standalone mode no longer depends on external services.

**Negative**
- No remote push from the PC to the phone when the app is closed.
- On iOS, notifications only work while the app is open.

**Neutral**
- The backend keeps optional FCM code (`ENABLE_FCM`), disabled by default for the
  mobile flow.
