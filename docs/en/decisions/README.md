# Architecture decisions (ADR) — index

Records of the project's important technical decisions. Each ADR explains the
context, the decision and its consequences.

## Format

Each file follows this template:

```
# ADR NNN — Title

## Status
Proposed | Accepted | Superseded by ADR-XXX | Deprecated

## Context
What problem or situation drives the decision?

## Decision
What was decided?

## Consequences
Positive, negative and neutral.
```
