# Changelog

All notable CocinaP releases are documented here.

Format based on [Keep a Changelog](https://keepachangelog.com/) and
[Semantic Versioning](https://semver.org/).

---

## [1.0.8] - Unreleased

### Fixed

- Publish an Android debug-signed APK that can be installed directly for
  testing instead of an unsigned release APK.
- Do not advertise an unsigned iOS package as an installable release; attach an
  iOS IPA only when Apple signing and a device provisioning profile are set up.

### Changed

- Advance the mobile package version to `1.0.8+8`.

---

## [1.0.7] - Unreleased

### Changed

- Capture RTSP frames for person detection once per second instead of twice
  per second, and avoid rebuilding the live video view for every capture.
- Use a 4 MiB RTSP demuxer buffer to balance latency and playback stability.
- Advance the mobile package version to `1.0.7+7`.

---

## [1.0.6] - Unreleased

### Changed

- Add an editable `/stream2` RTSP fallback for cameras that fail ONVIF setup,
  prefilled with the discovered camera address and entered credentials.
- Advance the mobile package version to `1.0.6+6`.

---

## [1.0.5] - Unreleased

### Changed

- Reduce the RTSP demuxer buffer to 4 MiB to limit live-camera playback latency.
- Mobile package version advanced to `1.0.5+5` for latency and camera testing.

---

## [1.0.4] - Unreleased

### Fixed

- Allow RTSP in the native video player's protocol whitelist so RTSP camera
  URLs are not rejected before playback.
- Show actionable RTSP connection guidance instead of a generic camera error.

### Changed

- Mobile package version advanced to `1.0.4+4` for physical-camera testing.

---

## [1.0.3] - Unreleased

### Fixed

- Retry ONVIF SOAP requests with HTTP Basic or Digest authentication when
  challenged by the camera, while preserving the original SOAP request body.
- Offer a direct RTSP URL fallback for discovered cameras when ONVIF stream
  negotiation is rejected; allow RTSP credentials to differ from ONVIF login.
- Keep camera dialog controllers alive until their routes close to avoid
  cancellation errors.

### Changed

- Mobile package version advanced to `1.0.3+3` for camera compatibility testing.

---

## [1.0.2] - Unreleased

### Added

- Local ONVIF camera discovery with secure credential handling and RTSP playback
  alongside HTTP/MJPEG in standalone mobile mode.
- Tests for ONVIF discovery response parsing and local endpoint validation.
- Complete bilingual documentation under `docs/es/` and `docs/en/`, including
  architecture, installation, user guide, REST API, development, testing/CI,
  security, troubleshooting, roadmap, glossary and architecture decisions.
- Documentation index in `docs/README.md`.
- Device/camera selector and connection tutorial in the Monitoring screen.
- QR-code generation dependency for the PC GUI.
- pytest suites for configuration, engine, analyzer, runner and packaging.
- GitHub Actions CI workflows for mobile builds and Python validation.
- Editor configuration for consistent formatting.
- Complete Python package metadata and development dependencies.

### Changed

- Mobile package version advanced to `1.0.2+2` for pre-release validation.
- Camera guides and platform support documentation now describe ONVIF discovery,
  RTSP limitations, physical-device validation and store-release blockers.
- English primary README with bilingual documentation links.
- English contribution and security policies.
- Explicit Android/iPhone platform support and QA documentation.
- Android APK and iPhone IPA artifacts generated by GitHub Actions.
- API keys moved from ordinary preferences to platform secure storage.
- Firebase/FCM removal clarified throughout the project documentation.

### Release blockers

- ONVIF/RTSP compatibility has not been validated on a representative camera
  matrix; the V380 Pro / AIT36106 remains unverified.
- Android and iPhone release builds require physical-device QA and production
  signing before store distribution.
- Review the exact libmpv/codec licenses shipped by the selected video packages
  and complete all applicable source-offer and notice obligations before
  commercial distribution.
- Replace publisher/privacy-policy placeholders and complete legal review.

## [1.0.1] - 2026-07-05

### Fixed

- PyInstaller dependencies include PIL, matplotlib and sympy required by
  Ultralytics/Torch.
- The YOLO model path resolves correctly in frozen builds through
  `sys._MEIPASS`.
- The HTML dashboard was removed in favor of the REST API.
- About screen updated to version 1.0.1.

### Changed

- PyInstaller hidden imports cover Zeroconf, Firebase Admin, PySide6 and PIL.
- Version bumped to 1.0.1.

---

## [1.0.0] - 2026-06-15

### Added

- Functional YOLO11n detection system.
- Native Windows PySide6 GUI with camera, configuration and alarms panels.
- Flutter mobile app with live MJPEG dashboard.
- Embedded web server with REST API, SSE and MJPEG endpoints.
- mDNS discovery for local-network server detection.
- Optional Firebase Cloud Messaging push notifications.
- Asynchronous sound alarms with fire, smoke and unattended-kitchen patterns.
- Configurable stove zone.
- Multi-level risk analysis.
- HSV, texture, flicker and shape analysis for fire detection.
- Color, motion, texture and edge analysis for smoke detection.
- Kitchen timer with pause, summary and automatic alerts.
- PyInstaller package and Inno Setup installer.
- Android foreground service.
- Windows startup and system-tray support.
